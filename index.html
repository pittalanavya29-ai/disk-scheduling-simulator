📚 Disk Scheduling Algorithms Theory Guide

1. FCFS (First-Come, First-Served)

Services requests in the exact sequential order they arrive in the I/O queue. Completely fair with zero starvation risk, but suffers from severe head wild oscillations across cylinders, leading to high seek times.

2. SSTF (Shortest Seek Time First)

Greedy selection: always selects the pending request closest to the current head position. Dramatically reduces total head movement compared to FCFS, but introduces a risk of starvation for distant requests under heavy loads.

3. SCAN (The Elevator Algorithm)

The disk arm sweeps in one direction, servicing all pending requests along the way until it touches the disk boundary (cylinder 0 or Disk Size - 1). It then reverses direction and sweeps back. Eliminates starvation and provides bounded wait times.

4. C-SCAN (Circular SCAN)

Provides a more uniform waiting time than SCAN. The arm sweeps in one direction to the boundary, then immediately performs a rapid circular return jump to the opposite boundary without servicing requests on the return trip. Treats cylinders as a circular ring.

5. LOOK

A smart optimization of SCAN. The arm looks ahead in the current direction and only travels as far as the furthest pending request in that direction. When no further requests exist ahead, it reverses immediately without travelling to the 0 or Max-1 boundary.

6. C-LOOK (Circular LOOK)

An optimization of C-SCAN. Moves only as far as the furthest request in the forward direction, then jumps directly to the furthest request at the opposite extreme without travelling all the way to cylinder boundaries.
